# Summary: Make a walking sprite for the mascot
## What was done
The Artist drew a four-frame walk cycle of 16 by 16 pixels. The first check found that the "walk" animation ran past the last frame; the Artist set it to frames 0 to 3 and the second check passed.
## Files
- art/walker/walker-sheet.png: the four frames side by side
- art/walker/walker.json: the frame data, with the "walk" animation
- art/walker/walker.gif: the looping animation
- art/walker/manifest.json: the list of the files and the colours used
