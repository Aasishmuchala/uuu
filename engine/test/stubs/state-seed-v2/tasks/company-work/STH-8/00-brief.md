# Brief: Make a walking sprite for the mascot
## The goal in the owner's words
Make a walking sprite for the mascot, four frames, small enough for the website footer.
## What done looks like
A sheet of four frames of a walk cycle, a data file and a GIF that loops, all in one folder.
## Must-haves
- Four frames, 16 by 16 pixels.
- One animation named "walk" that covers all four frames.
- Flat colours only, from the Sthyra palette.
## Nice-to-haves
- A GIF the owner can drop straight into a page.
## Anything unclear
None.
