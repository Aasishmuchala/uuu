# ContextMenuItem
Import: import { ContextMenuItem } from '@astryxdesign/core';

re-exported DropdownMenuItem for compound mode

## Props
| Prop | Type | Default | Needed | What it does |
|---|---|---|---|---|
| icon | IconType |  |  | icon before label |
| label | ReactNode |  |  | primary label text |
| description | ReactNode |  |  | secondary text below label |
| endContent | ReactNode |  |  | additional content after label+description |
| xstyle | StyleXStyles |  |  | StyleX styles for root container |
