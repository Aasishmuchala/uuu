# Repos catalogue for the company engine

Compiled 11 November 2026. 368 repositories: the 15 shared first, 153 from GitHub trending, and 200 found by searching each business function.

## How this was compiled

- **Round 1, trending:** GitHub's trending pages and the most-starred repositories created since August 2026.
- **Round 2, by function:** GitHub searches for the most-starred active projects in about 30 business functions (video, photo, design, CAD, CRM, ERP, finance, HR, projects, support, marketing, PR, dashboards, automation, agents, memory, security, chat), plus well-known projects checked to be still active.
- **Basis column:** `README` = the top of the README was read by a Sonnet reader (262). `known` = summarised from its description and prior knowledge, not re-read (60). `listed` = description only (31). `earlier` = read earlier in this session (15).
- **Not verified:** nothing here was installed or run. Star counts are as GitHub reports them. Licences come from GitHub and each README; read the licence file before shipping anything.
