## Question

Which agent actions need the owner's approval, and which run without asking? Decide for deleting, installing software, changing files outside a task's workspace, git pushes and anything that spends money.

## Answer

Decided with the owner on 11 November 2026.

Agents work freely inside their own task folder. Everything else is blocked outright, not asked. The only thing that reaches the owner is finished work, for a final yes.
