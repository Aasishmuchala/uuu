# Each agent's budget

Label: wayfinder:grilling
Type: grilling
Status: resolved
Blocked by: 03, 06

## Question

What budget does each agent get, and what happens when it runs out, given that the owner pays by plan and not per token?

## Answer

Decided with the owner on 11 November 2026.

Money budgets do not apply on subscription plans, so the limits are: one task at a time per agent, a time limit per run, and agents run only while the owner has the engine switched on. The plan's own quota is the ceiling. Reason: the agents share the owner's Claude plan with the owner's own work.
