# 05: What is built and kept: the books, the home server, knowledge, marketing drafts, the Drafter's tools

**What to build:** The parts of the first plan that are finished and stay as they are. One system of record holds the books, customers, support and staff, with a draft-only login for each department agent. The home server gathers what waits for the owner, takes a goal, and serves each department's figures. Company documents can be added and searched, agents keep lessons, content drafts are collected for approval, and the Drafter turns a description into a CAD file with measured sizes.

**Blocked by:** None (can start immediately)

**Status:** done

**Plan tasks:** B1, T2, T8, T10, T11, T12, T13, T14 (first plan)
