# 08: Knowledge and lessons

**What to build:** The owner drops company documents into a Knowledge page and searches them. Agents can read those documents from inside the fence, and cannot change them. Each role keeps a short list of lessons that its agent reads before starting work and adds to when it learns something.

**Blocked by:** 01, 05

**Status:** ready-for-agent

**Plan tasks:** T12

- [ ] The owner can add a document as text, see the list, open one and delete one
- [ ] Search finds a document by its words and shows the matching passage
- [ ] An odd search, such as a lone quote mark, gives no error
- [ ] A document placed in the folder by hand is picked up
- [ ] Agents can read the knowledge folder and cannot write to it
- [ ] Each role has a lessons list the owner can read on the Knowledge page
- [ ] An agent can add a line to its own role's lessons and nowhere else outside its task folder
- [ ] No extra service runs for any of this
