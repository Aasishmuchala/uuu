# 10: The Drafter and the Studio page

**What to build:** The owner asks for a simple part in plain words and gets back a CAD file with its measured size and volume. A Drafter agent does this inside the fence. The Studio page lists what agents have drafted, with files the owner can download.

**Blocked by:** 01, 05

**Status:** ready-for-agent

**Plan tasks:** T14

- [ ] The Drafter's tools install with a check on free disk first, and never take the Mac below its floor
- [ ] A test part (a 60 by 40 by 5 mm plate with two 6 mm holes) comes out with the right size and volume
- [ ] The Drafter can use its tools from inside the fence, and an agent without that allowance cannot
- [ ] Every CAD result has the file, the script that made it, and its measurements in millimetres
- [ ] The Studio page lists CAD parts with size and volume, and other drafted files, each with a download
- [ ] When the tools are not installed, the page says so and how to install them
- [ ] The page says no renderer is connected
